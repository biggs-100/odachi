# the-error-branches

## What must exist
- the error branches of the refusal and of the review rule answer as they promise, and a test says so

## Done when
- a store that cannot be checked or written is reported, and the refusal never names a path it did not write
- ReviewOwed answers RequireReview the same the gate does, and an unreadable project is an error rather than a silent not owed
- progress reports a failing Review callback instead of claiming anything
- every branch covered has a test that fails if the branch is inverted

## Not included (first version)
- the refusal message and the store layout
- new behaviour in check or progress
- the boundary walk over older verdicts

## Decisions taken
- It is used from the computer.
- There is no sensitive data in the first version.
- First usable version: today.
- Wants to learn: how to test a branch you cannot reach by accident.
