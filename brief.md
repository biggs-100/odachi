# the-design-surface-any-agent-can-use

## What must exist
- everything gentle-design has, working in any agent odachi installs into: the skill, the design folder with its manifest and comments, a canvas any client can drive, and the handoff to the real stack

## Done when
- a skill named design ships with odachi and travels to every client through setup and pack
- a design is a folder with self-contained artboards, a manifest and a comments file, and the formats are pinned by a versioned fixture
- the canvas is a command any agent can run -list, open, stop- and writes comments the agent reads from disk
- the design system sync reads the project tokens and never edits them

## Not included (first version)
- a stored proof is never rewritten, whatever the writer learns
- the sixteen bundled skills that ship today are not edited; a new one arrives as its own feature

## Decisions taken
- It is used from the computer.
- There is no sensitive data in the first version.
- First usable version: today.
- Wants to learn: por que una capacidad se reparte como protocolo y no como herramienta.
