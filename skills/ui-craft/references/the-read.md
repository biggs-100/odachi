# The read

Build it, screenshot it, and read it against this page. A screen nobody looked at
is a screen nobody checked.

## The checklist

- The winner: one element leads at a glance, and it is the one the task needs.
- The job: the screen serves the leading job and says it in its first viewport.
- The five states: empty, loading, error, disabled and focus, on every control, each with its copy
  (`states-and-copy.md`), not a default panel.
- The worst content: the longest name, the biggest number, an unbreakable email, zero items.
- The contrast: measured, not estimated; 4.5:1 for text, 3:1 for large text and UI edges.
- The keyboard: focus moves into an overlay and returns to its trigger, Escape does not discard work,
  and nothing essential is reachable only by hover.
- The zoom: at 200%, text reflows without clipping and no label is truncated by a fixed height.
- The tokens: one radius per level, one shadow per elevation, one icon family.
- The motion: every animation answers feedback, continuity, hierarchy or story.
- The screenshot: taken after the last change, and looked at.

If a row fails, the screen is not done: fix it and read it again. A screen that
passes every row but still feels generic is a decision nobody made; go back to the
order and find it.
