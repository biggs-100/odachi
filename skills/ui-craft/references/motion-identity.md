# The signature move

A product is remembered for one interaction, and it is rarely the one that took the
most work. The hover that reshapes the row, the panel that arrives from the edge it
belongs to, the empty state that draws itself: motion carries identity when it is
chosen once and repeated, and it carries nothing when every element enters from below.

`motion.md` owns the values -the two properties, the durations, the reduced-motion
pass-. This page owns the one decision above them: what the product's move is.

## Choose one, and say what it says

- **One move**, in the place the product is used most: the primary action, the row, the
  transition between two views of the same thing.
- It answers a question the layout cannot: where the thing came from, what it belongs
  to, what just changed.
- It repeats. A signature that appears once is a decoration; the same easing on the
  same trigger is what makes it a language.
- It survives being still: with motion off, the same information arrives by placement
  or by a state change. `accessible-and-adaptive.md` owns the reduced-motion pass.

## Three moves that are worth copying, and what each costs

1. **The continuity move**: the element that was a row becomes the page, same position,
   same content, expanded. Costs a shared layout animation and a stable id.
2. **The acknowledgement move**: the control answers the press before the work starts -
   a compress, a lock, a check that then fills. Costs discipline: it must never claim
   success before the result is known (`states-and-copy.md`).
3. **The arrival move**: a region enters from the direction of its cause -the drawer
   from the edge it belongs to, the row from the button that created it. Costs a rule
   about where things come from, which is the same rule that makes the layout legible.

## What is not a signature

- Staggered cards fading up on scroll: the identical move of every template, and it
  delays the content the person came for.
- An animated hero that plays once and then never again.
- A spinner as the only motion in the product: that is a state, not an identity.
- Parallax, cursor followers and physics on decorative shapes: motion that answers no
  question about the work.

## Where it is measured

The move is a frame budget, not a taste: it runs on the cheapest device the product
supports, it never blocks the first interaction, and it is the first thing dropped when
the machine is slow. A signature that costs the person a second is a tax with a name.
